# 家庭共同記帳規格與使用方式

此文件是原始個人版規格的家庭版增補，以 2026/10/04 核准的方向實作。

## 使用範圍

- 一個家庭共用同一本帳，收入與支出全部彼此公開。
- 不設登入、密碼、私人帳目或成員權限；任何能連線的人都能查看與修改。
- 兩支手機必須連到同一個後端網址與 SQLite 資料庫，不能各自啟動一份獨立帳本。
- 「操作人」只是自行選擇的記錄標記，不是身分驗證。

## 初次設定

1. 到設定把「成員一」「成員二」改成容易辨識的名字。
2. 每支手機選自己的「這台裝置常用操作人」。此選擇只儲存在該瀏覽器 localStorage，不同步到另一台裝置。
3. 新增或修改交易時，可另外指定「本次操作人」。尚未選擇或已停用的操作人不能送出。
4. 新增預設歸屬常用操作人，可改成另一位成員或「家庭共同」。這不影響任何人的查看權限。

## 歸屬與操作紀錄

| 資料 | 規則 |
| --- | --- |
| 收支歸屬 | 個人成員、家庭共同；舊資料另有歸屬待確認 |
| 建立者／時間 | 新增時記錄，後續修改不覆寫 |
| 最後操作人／時間 | 修改、刪除、復原時更新 |
| 刪除者／時間 | 記錄最近一次刪除；復原後資料庫保留該紀錄 |
| 成員 | 固定 ID，可改名、停用與重新啟用；不刪除歷史關聯 |

畫面顯示成員目前名稱，改名會同步反映到歷史資料；這不是逐次異動稽核日誌。停用成員不能操作或成為新交易歸屬，但編輯舊帳可保留原停用歸屬。

## 查詢與統計

- 預設顯示全家收入、支出與結餘。
- 可篩選個別成員、家庭共同、歸屬待確認；清單、摘要、分類圖及六個月趨勢使用相同歸屬條件。
- 家庭共同帳目全額計算一次，不平分給成員、不另算欠款或結算。
- 已刪除帳目不計入統計；已刪除清單跨全部月份，仍可套用歸屬與收支類型篩選。
- 切換頁面、回到前景或按重新整理會更新資料；不推播即時變更。正在編輯的表單保留草稿，儲存時檢查版本。

## 同時操作與復原

- 修改、刪除、復原必須帶目前版本；先儲存者成功，後儲存的舊版本收到 HTTP 409，不覆蓋新資料。
- 編輯視窗提供「捨棄本次修改，載入最新內容」。若已被刪除，可關閉並到已刪除清單查看。
- 新增表單每次開啟產生一個 UUID，重試沿用；資料庫唯一索引防止同時重送造成重複帳目。同一 UUID 搭配不同內容會回 409。
- 不提供離線記帳佇列。網路中斷後可在原視窗重試；若關閉視窗，請先重新整理確認有無成功儲存，再新增。
- 刪除前確認，刪除後可到「帳目 → 已刪除帳目」選擇交易與操作人復原。不提供永久清空。

## 資料庫升級

`20261004050755_FamilyLedger` 在既有資料表加入家庭欄位、版本、刪除標記與送出 UUID，並建立兩個預設成員。既有金額、日期、分類、帳戶、備註保持不變。

舊帳目設定為 `Unknown`、版本 1；建立者與最後操作人留空，顯示「未記錄」，不猜測屬於哪一人。可透過逐筆編輯補上歸屬。沒有批次指派功能。

升級前停止後端並備份 SQLite 資料庫及存在的 `-wal`、`-shm` 檔案；再啟動新版自動套用 Migration。使用固定資料庫絕對路徑，Docker 請沿用原 volume。若回復舊程式，應使用升級前備份；回復備份會丟失備份之後新增的帳目。

## API 異動

舊版前端不具送出 UUID、操作人及版本欄位，升級後需關閉舊 App 分頁並重新開啟新版。

- `GET /api/members`：包含停用成員。
- `POST /api/members`、`PUT /api/members/{id}`：`{ name, isActive }`。
- `POST /api/transactions`：新增 `ownership`、`ownerMemberId`、`operatorId`、`clientRequestId`。
- `PUT /api/transactions/{id}`：必填 `version`、`operatorId`、歸屬與原交易欄位。
- `DELETE /api/transactions/{id}`：JSON body `{ operatorId, version }`，軟刪除。
- `POST /api/transactions/{id}/restore`：JSON body `{ operatorId, version }`。
- 清單與三個統計端點支援 `ownership=Personal|Shared|Unknown`、`ownerMemberId`。Shared／Unknown 不可搭配成員 ID。
- 清單另支援 `deleted=true`；一般查詢及單筆 GET 排除已刪除資料。
- 回應包含歸屬名稱、建立／最後操作／刪除的人名與時間，以及 `version`、`isDeleted`。

此版本延續原有家庭網路部署方式，未新增公開網站或外部服務。
